[패키지 구성]
- index.html   : 네이버 블로그 형태의 관찰 노트 메인 페이지
- style.css    : Pretendard 폰트 시스템 및 미니멀 무채색 블로그 디자인 스타일시트
- app.js       : 목록열기, 이웃추가 모달, 공감(하트), URL 복사 토스트 반응형 로직
- assets/      : 프로필 이미지 및 본문 관찰 노트 고화질 이미지 자산

[개발자 및 작업자 가이드]
1. index.html 파일만 브라우저로 열면 바로 전체 블로그 페이지가 렌더링됩니다.
2. Pretendard 폰트는 CDN 형태로 헤더에 연결되어 있습니다.
3. 이미지 및 자산 변경 시 assets/ 폴더 내 파일 경로를 참조해 주세요.
